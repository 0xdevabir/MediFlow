## What was built (under `com.mediflow.directory`, `templates/directory/**`, `messages/directory_*`, V200–V249)

### Schema — `V200__directory_extensions.sql`
- `hospital.parent_hospital_id` (branches) + `ambulance_phone` (F7)
- `department.clinical` (public list shows clinical only)
- `practitioner.specialty`
- Unique `(practitioner_role_id, starts_at)` on `slot` + time/count checks
- Triggers: package items must be `direct_allowed`; cannot clear `direct_allowed` while a test is in a package

### Schedule / slots
- `WeeklySchedule` JSON parser + overlap/range validation
- `SlotPlanner` → planned windows
- `SlotGenerationService` materialises / reconciles **14 days** ahead (configurable): no duplicates (`ON CONFLICT DO NOTHING`), never deletes booked slots, closes unbooked-but-referenced slots (`capacity=0`)
- `DirectorySlotJob`: nightly cron + startup (`@Order(100)`)
- On admin schedule/active change → `PractitionerScheduleChanged` (local event; requested in shared `DomainEvents`)

### Public search (no login)
- `DirectoryQueryService.search` / `freeSlots(roleId, date)` (for T04) / direct tests / packages
- `DirectoryJdbc` read model (joins + V200 columns the T00 entities do not map)
- `DirectoryPublicSecurityConfig` permits GET `/directory`, `/directory/search`, `/directory/tests`, `/directory/packages`
- `DirectoryRootForwardFilter`: `GET /directory` → `/directory/search` (avoids clash with T00 `PlaceholderController`)
- Templates: `directory/search.html`, `directory/tests.html`
- i18n: `directory_en.properties`, `directory_bn.properties`

### Admin CRUD (`ROLE_ADMIN`) — `/directory/admin/**`
- Hospitals (incl. parent/ambulance), departments (clinical flag), practitioners (specialty), practitioner roles + schedule JSON, lab tests, lab packages (direct-only validation)
- Audited via `AuditPort`; schedule edits publish `PractitionerScheduleChanged`
- Templates under `templates/directory/admin/`

### Dev seed (`DirectoryDevSeeder`, profile `dev`, `@Order(10)`)
- 3 hospitals (DMCH + outdoor branch + BIRDEM)
- 6 clinical departments + 1 non-clinical Administration
- 10 doctors with weekly schedules (first linked to `doctor` user when present)
- Direct tests: FBS, RBS, CBC, Lipid, Urine R/E, HbA1c (with LOINC) + **Basic Health Check** package
