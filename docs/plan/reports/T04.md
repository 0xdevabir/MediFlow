# T04 — Appointments, check-in, queue, triage, Red Alert & ER: report

Status: code complete on `feat/T04-appointment-queue`. **Tests were not run** (coordinator rule: no `mvnw verify` / test runs, no Docker). `./mvnw -q -DskipTests test-compile` is green.

## What was built
All under `com.mediflow.appointment/**`, `templates/{appointment,queue,er}/**`, `messages/appointment_{en,bn}.properties`, `V250__appointment_queue.sql`, plus `static/js/appointment-queue.js`.

### Schema (V250)
- `appointment_booking_meta` — check-in code, emergency flag, reschedule link
- Partial unique index: one live booking per patient per slot
- Slot capacity check constraint
- `appointment_token_counter`, `appointment_queue_meta`, append-only `appointment_queue_override`
- Append-only `appointment_triage_history`
- `red_alert` extensions: `assigned_er_user_id`, `acknowledged_by`, `source`, handover fields (for T01 scoped ER access)

### Booking
- `BookingService`: patient self-book, front-desk on behalf, cancel, reschedule, emergency flag
- Optimistic locking on `slot.bookedCount` (+ DB constraints) to prevent double-booking
- Publishes `AppointmentBooked` / `AppointmentCancelled`
- Local `SlotCatalog` / `JpaSlotCatalog` (T03 directory port not available on this branch)

### Check-in
- QR / check-in code, or two identifiers (MRN / national id / phone)
- Daily per-doctor token (`T001`…), `queue_entry` + `appointment_queue_meta`, encounter shell
- Publishes `AppointmentCheckedIn`

### Queue
- Pure `QueueOrdering` (§6.2): CRITICAL never OPD; URGENT before NORMAL; among URGENT borderline/critical vitals first; NORMAL by slot/arrival; nurse override via sort-key nudge
- Board, patient status (“N ahead”), doctor call-next, nurse move-up / reorder (reason required, override log + `AuditPort`)
- Live updates: SSE `/api/queue/stream` + 10 s poll fallback (`appointment-queue.js`)

### Triage & Red Alert
- Nurse sets CRITICAL / URGENT / NORMAL + symptom severity; publishes `TriageLevelSet`
- CRITICAL → `RedAlertService.raise`: row, OPD removal, ER/push notify via `NotificationPort`, `RedAlertRaised`
- `VitalsEscalationListener`: `VitalsClassified` CRITICAL → auto Red Alert even if nurse chose lower
- ER UI: active alerts, acknowledge, handover ADMITTED / REFERRED / DISCHARGED

### UI / i18n
- Pages: book, detail, check-in, queue board/doctor/patient, ER board/detail
- EN + BN message bundles
- `ModuleRootForwardFilter`: GET `/appointments` and `/queue` (nav targets still owned by T00 placeholder) forward to `/appointments/home` and `/queue/home`
