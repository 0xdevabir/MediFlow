## What was built

### Schema & domain (V350)
- `rx_prescription_meta`, `rx_item_meta`, `rx_safety_flag`, `rx_flag_ack`, `rx_incident`
- `prescription_item.generic_id` nullable (unknown brands)
- DB triggers: no auto-sign; signed Rx immutable except status → AMENDED / ENTERED_IN_ERROR; items mutable only while DRAFT

### Safety (`safety/`)
- `RxDrugDictionary` + `DictionarySnapshot` + `RepositoryRxDrugDictionary` (60 s refresh of T08 `drug_*` tables)
- `ConfidenceGate` — item conf = min(drug, dose, frequency); Table 20 / 85 % rule (PREFILLED / NEEDS_REVIEW / UNKNOWN / HARD_STOP)
- `SafetyEngine` — DOCX Table 13: allergy, severe interaction, dose range, duplicate therapy, NSAID+renal, pregnancy, antihypertensive+low BP, unknown
- `SafetyEvaluationService` — loads allergies/conditions/vitals/active meds, persists flags, re-applies gate
- `ThresholdSettings` — read-only `ai.confidence.threshold`

### Draft / AI / SSE
- `DraftService` — create (TEXT/PHOTO/MANUAL), items, confirm, override (`ai_flag_override` + `rx_flag_ack`), photo → `ObjectStoragePort`
- `AiGatewayService` — `POST /api/prescriptions/{id}/ai-jobs` → 202 + jobId; publish `ai.rx` / `ai.rx.requests` (no patient ids); consume `ai.rx.results`; circuit breaker; discard after 10 s UI fallback
- `AiJobSseHub` + `GET /api/ai-jobs/{jobId}/events`; poll `GET /api/ai-jobs/{jobId}`
- `static/js/prescription/ai-job.js` — SSE + poll + 10 s → manual + discard late results

### Sign / revoke
- `SignService` — blocked on CRITICAL / unresolved NEEDS_REVIEW|UNKNOWN; licence on `Practitioner`; MFA via `RxMfaStepUp`; publishes `PrescriptionSigned`; AI KPI ACCEPTED/CORRECTED
- Addendum → new DRAFT linked by `amends_prescription_id`, parent → AMENDED, `PrescriptionAmended`
- `RevokeService` → ENTERED_IN_ERROR, incident (review due +24 h), notify via `NotificationPort` + `PrescriptionRevoked`

### Web
- Thymeleaf: list / new / review / patient copy (printable + QR payload token)
- Messages en + bn
- Controllers under `/prescriptions` and `/api/**`
