# T07 — Lab coordination incl. direct tests (M5): report

Status: code complete on `feat/T07-lab`. **Tests were not run** (no `./mvnw verify` / no Docker per coordinator). `./mvnw -q -DskipTests test-compile` is green.

## What was built
All under Owns: `com.mediflow.lab/**`, `templates/lab/**`, `messages/lab_{en,bn}.properties`, Flyway `V400`–`V401`.

### Schema & seed
- `V400__lab_module.sql`: `lab_order_detail` (booking ref, QR token, slot, assigned tech, resulted_by), `lab_reference_range` (LOINC/UCUM + ref/critical), `lab_result_value`, `lab_critical_task` (phone patient).
- `V401__lab_catalog_seed.sql`: direct-allowed panel (FBS/RBS/HbA1c/CBC/lipid/urine) vs doctor-only (creatinine, K, troponin, TSH, X-ray); ranges; two packages.

### Domain / services
- Entities: `LabOrderDetail`, `LabReferenceRange`, `LabResultValue`, `LabCriticalTask`, `ResultFlag`, `BookingChannel`.
- `ResultFlagCalculator` — critical limits win; unknown numeric rejected; sex-specific range pick.
- `LabOrderService.orderForEncounter` (DOCTOR) + `bookDirectForSelf` / `bookDirectForWalkIn` (DIRECT only if `direct_allowed`; packages only when every item is direct-allowed). Publishes `DomainEvents.LabOrderCreated`.
- `LabWorkflowService`: collect (QR match → barcode + assign tech) → receive → upload PDF (MinIO via `ObjectStoragePort`) + structured values with flags → verify **by a different tech** → `LabReportVerified`; critical → `lab_critical_task` + duty-doctor `NotificationPort` alerts.
- `LabQueryService`: patient reports **hide values/PDF/summary until VERIFIED**; tech queue filters to unassigned or own assigned orders; critical task list.

### Web
- `/lab/home`, `/lab/direct`, `/lab/reports`, `/lab/reports/{id}`, `/lab/queue`, `/lab/queue/{id}`, `/lab/encounters/{id}/orders`.
- Messages en + bn; flash via `LabExceptionAdvice` for `LabRuleException`.
