# T08: Pharmacy dispensing & DGDA drug dictionary (M6): report

Status: code complete on `feat/T08-pharmacy`. **Tests were not run** (coordinator instruction: no `mvnw verify` / test execution, no Docker). `./mvnw -q -DskipTests test-compile` is green.

## What was built

Owns: `com.mediflow.pharmacy/**`, `templates/pharmacy/**`, `messages/pharmacy_{en,bn}.properties`, Flyway **V450–V452**.

### Schema (V450–V452)
- `V450__pharmacy_schema.sql`: pg_trgm (best-effort), name indexes, `drug_dictionary_import`, `drug_data_provenance`, `pharmacy_stock_batch`, `dispense_batch`, `pharmacy_request`, `pharmacy_rx_block`.
- `V451__dgda_illustrative_seed.sql`: ~50 BD trade names (Napa→Paracetamol N02BE01, Seclo→Omeprazole A02BC01, Ciprocin→Ciprofloxacin J01MA02, …) tagged `ILLUSTRATIVE_SEED`.
- `V452__drug_reference_placeholder_seed.sql`: curated interactions + dose limits tagged `PLACEHOLDER_SEED` (“placeholder — needs licensed source”).

### Dictionary (`dictionary/`)
- `DrugDictionaryPort` + `DrugDictionaryService`: exact brand/generic (never guesses), fuzzy `suggest` via pg_trgm or Java trigram fallback, Redis-safe `DictionaryCache`, interactions / dose limits.
- `DgdaImportService`: versioned admin CSV import with unmapped report.
- `GET /api/internal/dictionary/export` (`DictionaryExportController`) for T09; auth via `X-Mediflow-Internal-Key` = `mediflow.pharmacy.internal-api-key` / `MEDIFLOW_PHARMACY_INTERNAL_API_KEY` (`PharmacyInternalSecurityConfig`).
- Admin UI: `/pharmacy/dictionary`.

### Stock (`stock/`)
- Per-hospital `pharmacy_stock` + batches; quantity = sum of batches; low-stock list; FEFO-friendly batch listing.

### Dispensing (`dispensing/`)
- Signed prescriptions only (read-only items — no updates to `prescription_item`).
- Identity required: QR (safe default rejects until T02 port) **or** two distinct identifiers (`PatientIdentityPort`).
- Dispense → `dispense` + `dispense_batch`, stock consume, publish `DomainEvents.MedicationDispensed`, audit.
- Out of stock: substitution request (same generic) → doctor approval (`/pharmacy/substitutions` interim) or refer elsewhere; send-back with reason.
- `PrescriptionRevokedListener`: inserts `pharmacy_rx_block`, alerts if already dispensed.

### UI
- `/pharmacy` home (queue, low stock), `/pharmacy/rx/{id}`, `/pharmacy/stock`, substitutions, dictionary. Messages en + bn.

### Tests (written, not executed)
- Unit: `DrugNamesTest`, `CsvReaderTest`, `DefaultPatientIdentityVerifierTest`.
- IT: `DrugDictionaryIT` (Napa/Ace → same Paracetamol; unknown empty), `DispensingIT` (identity + revoke guards).
