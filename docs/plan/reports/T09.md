# T09 — AI service: OCR, entity extraction, DGDA normalisation, confidence

Status: code complete on `feat/T09-ai-service`. **Tests were not run** (coordinator rule: no pytest / Docker). Modules compile; a manual smoke of the TEXT pipeline matched Napa→Paracetamol and unknown→null/conf 0.

## What was built (`ai-service/**` only)

- **Contract** (`mediflow_ai/contract.py` + JSON Schemas): request/result models for `ai.rx.requests` / `ai.rx.results` / `ai.rx.dlq`. Extra properties (e.g. patient ids) are rejected. Poison messages carry `jobId` + reason only.
- **Config** (`config.py`): `MEDIFLOW_AI_*` env vars — AMQP, MinIO, dictionary URL/file, OCR backend, 8 s job timeout, UNREADABLE gates, calibrator path.
- **Pipeline** (`pipeline.py`):
  1. OpenCV preprocess (deskew, denoise, CLAHE, Otsu) + quality gate
  2. OCR: Paddle → Tesseract → none (`ocr/`); Fake backend for CI; Bangla numerals → ASCII
  3. Rule-based entity extract (`extract.py`): drug n-grams, strength, dose, route, frequency (`OD/BD/TDS/QID/HS/PRN/STAT/QnH/1+0+1`), duration
  4. RapidFuzz dictionary (`dictionary.py`): brand→generic→ATC; **no match → null + drug conf 0**
  5. Isotonic calibrator (`calibrate.py`): file if present, else identity
- **Worker** (`worker.py`): aio-pika, durable queues on exchange `ai.rx`, DLQ on poison, per-job `asyncio.wait_for` 8 s → `ERROR` result.
- **FastAPI** (`app.py`): `GET /health`, `GET /metrics` (prometheus_client stage latency + job counts), `POST /v1/predict` for local TEXT/IMAGE debug. Worker starts on lifespan when AMQP URL set.
- **Privacy**: logging filter drops PHI-like keys; logs jobId / timings / modelVersion / engine only. Network clients only for RabbitMQ, MinIO, dictionary URL.
- **Illustrative dictionary** (`data/illustrative_dictionary.json`): Napa/Seclo/Ciprocin + ~60 BD brands, marked illustrative; overridden by file/HTTP export.
- **Dockerfile**: python:3.11-slim + tesseract; paddle layer commented; `/models` volume; ONNX bake path documented in README.
- **Eval** (`eval/`): synthetic prescription renderer, CER / top-1/top-3 / field F1 / ECE + SVG reliability diagram.
- **Tests** (written, not executed in this session): contract schema, numerals, frequency/duration, dictionary (Napa variants + unknown), extract line, pipeline e2e (text/image/unreadable/Bangla/calibrator), worker timeout + poison DLQ, eval metrics.

## Safety invariants (PLAN §6)

- AI produces a **draft** only (queue result / `/v1/predict`); never signs, dispenses, or writes the record.
- Unknown brand → blank generic/ATC, `conf.drug = 0` (never guess).
- Item confidences are per-field; Java (T06) owns `min(drug,dose,frequency)`, the 0.85 gate, and contradiction checks.
- No patient identifiers on the wire.

## Deviations

1. **spaCy NER not shipped.** Extraction is rule-based (covers the acceptance frequency / Bangla / brand cases). spaCy would bloat the image and needs a model download; can be layered later behind the same `extract_line` output.
2. **PaddleOCR optional.** Base Docker image installs Tesseract only; paddle extra is opt-in (`.[paddle]` / Dockerfile comment) because wheels are large.
3. **Illustrative dictionary** used when no T08 export is configured (`allow_illustrative_dictionary`, default true). Production should set `MEDIFLOW_AI_DICTIONARY_URL` and ideally disable the seed.
4. **`/v1/predict`** is a debug helper (same result schema); production path is the queue worker.
