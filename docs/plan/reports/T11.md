## What was built

### Audit (`com.mediflow.audit/**`, V550, `templates/audit/**`, `messages/audit_*`)

- **`HashChainAuditPort`** — real `AuditPort` (T00 signature). Appends
  `audit_event` under `pg_advisory_xact_lock` in a `REQUIRES_NEW` transaction;
  `hash = SHA-256(prev_hash || canonical row)`; `purpose` / `outcome` live in
  `details`.
- **`AuditChainService`** — scheduled + on-demand verifier; admin page shows
  “chain integrity OK / broken at #n”; detects content, link, and head
  truncation vs previous check.
- **`AuditQueryService`** — patient `/audit/me` (role + name + purpose); admin
  search (user, patient, action, date). Details JSON is not shown clinically.
- **`AuditAnomalyService`** — hourly scan for > N distinct patients / user
  (`audit.anomaly.patients-per-hour`); admin review sign-off.
- **`AuditExportService`** — CSV export; retention years from
  `audit.retention.years` (export only — append-only table never deleted).
- **Flyway `V550__audit_hash_chain.sql`** — `seq` identity, `audit_chain_check`,
  `audit_anomaly`, seed settings.

### Admin (`com.mediflow.admin/**`, `templates/admin/**`, `messages/admin_*`)

- **Dashboard** `/admin` — links to T03 `/directory`, T01 break-glass review,
  audit, settings, analytics, DHIS2. No clinical chart content.
- **`SettingGovernanceService`** — versioned `system_setting` via
  `SystemSettings`; dual ADMIN + CLINICAL_APPROVER for governed keys; **raise-only**
  `ai.confidence.threshold`; self-approve rejected; vital_rule / drug_interaction
  JSON apply on approval; non-governed keys (e.g. audit.*) admin-direct.
- **`AnalyticsService`** — aggregated KPIs only (times, counts, ratios).
- **`Dhis2ExportService`** — anonymised monthly `dataValueSets` JSON download;
  live push intentionally absent.
