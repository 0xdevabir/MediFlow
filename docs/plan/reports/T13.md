## What was built

### Containers
- `backend/Dockerfile` — multi-stage Maven build → distroless Java 21 nonroot, layered jar, JVM healthcheck against `:8081/actuator/health`.
- `ai-service/Dockerfile` — multi-stage slim Python 3.11, non-root uid 10001, `api|worker` entrypoint with Docker-secrets loader. Tunable via `AI_APP_MODULE` / `AI_WORKER_MODULE` (T09).
- `infra/docker-compose.prod.yml` — postgres, redis (password from secret), rabbitmq (+ prometheus plugin), minio, backend, ai-api, ai-worker (scale with `--scale`), nginx, prometheus, alertmanager, grafana.
- Networks: `edge` (published 80/443), `app` (services + optional Grafana/Prometheus ports), `data` (`internal: true` for DB/cache/queue/object store).
- Secrets via Compose `secrets:` + `infra/scripts/gen-secrets.sh`; TLS via `infra/certs/gen-dev-certs.sh` (outputs gitignored).

### Edge / TLS
- `infra/nginx/` — TLS 1.3 only, HSTS + security headers, gzip, rate limits on login/MFA/booking/API/AI-job POST, SSE locations with `proxy_buffering off`, `/actuator/` and `/api/internal/` blocked at the edge.

### Monitoring
- `infra/prometheus/` — scrapes backend Actuator, ai-api, ai-worker, RabbitMQ per-object metrics; alert rules for AI down, queue backlog/no consumers, DLQ, audit chain broken/stale, API p95 &gt; 500 ms, AI p95 &gt; 5 s, error rates.
- `infra/alertmanager/alertmanager.yml` — default receiver (wire webhook/SMTP via `*_file` secrets per deploy).
- `infra/grafana/` — Prometheus datasource + provisioned **MediFlow overview** dashboard (API/AI p95, queues, SSE, Red Alert, audit chain, scrape up).
