# T02 → other modules: change requests

## T00 — PlaceholderController

`PlaceholderController` maps `GET /patients` to `coming-soon`. T02 owns patient HTML under `/patients/**` (`/patients/search`, `/patients/{id}`, `/patients/register`, …).

Please remove `/patients` from the placeholder `@GetMapping` list so the nav link can land on the real module. Suggested landing once removed: front desk → `/patients/search`; patient role → `/patients/me` (T02 can add a thin `GET /patients` redirect after the placeholder mapping is gone).

Until then T02 does **not** map `GET /patients` (avoids ambiguous mapping) and uses `/patients/search` and `/patients/me`.

## T01 — ConsentService

T02 codes against local `PatientConsentGateway` (default writes TERMS + DATA_PROCESSING into the shared `consent` table with version `REGISTRATION/v1`). When T01 merges, optionally provide a `@Primary` / `@ConditionalOnMissingBean` adapter that delegates to `ConsentService` so both modules share one code path. No shared-port change required for Wave 1.
