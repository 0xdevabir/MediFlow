# V2-05 — cross-module requests

## V2-01 — wire appointment home tiles

`templates/appointment/home-tiles.html` exposes fragments `frontDesk`, `nurse`, `doctor`, `er` with today's counts via `@appointmentHomeStats`. Please replace the placeholder tiles in `templates/home.html` with e.g.:

```html
<div th:replace="~{appointment/home-tiles :: frontDesk}"></div>
```

(and similarly for nurse / doctor / er sections). No shared CSS changes required; fragments use existing `mf-tile` / `btn-teal`.

## V2-02 — ER assignee ACL

Red Alert raise now **always** sets `assigned_er_user_id` when any enabled `ROLE_ER` exists (logged-in ER preferred, else least-loaded on-duty ER for the hospital via `practitioner_role`). Acknowledge no longer overwrites assignee (only `acknowledged_by`). Please consume the column in `PatientAccessPort.isErAssigned` / `AccessPolicy` ER_ASSIGNED.
